# Kalkulator Podatkowy

Ten kalkulator służy do porównania dwóch form działalności gospodarczej:
- JDG (ryczałt 3%)
- Sp. z o.o. (CIT 9% / Estoński)

## Jak korzystać z kalkulatora?
1. Otwórz plik `kalkulator-podatkowy.xlsx`.
2. Wprowadź dane dotyczące amortyzacji, inwestycji i podatków.
3. Kalkulator automatycznie obliczy różnice w kosztach i korzyściach między wybraną formą działalności.
4. Przeanalizuj wyniki, aby podjąć świadomą decyzję o wyborze formy działalności.

## Uwaga
Upewnij się, że masz zainstalowany program obsługujący pliki Excel, aby korzystać z kalkulatora.
